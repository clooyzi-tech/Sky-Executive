PROJECT: LIV.INN BOUTIQUE HOTEL WEBSITE

Create a premium, modern, elegant boutique-hotel website for "Liv.inn Hotel".

The overall visual direction should communicate:
- Luxury
- Warmth
- Comfort
- Trust
- Premium hospitality
- Modern boutique hotel
- Clean and sophisticated experience

IMPORTANT:
Do NOT make the website predominantly black or dark.

The current Liv.inn logo uses black + gold, but the BLACK should remain primarily inside the logo and be used only in small UI elements such as text, borders, icons, overlays, and selected sections.

The MAIN WEBSITE THEME must be LIGHT.

==================================================
1. CORE COLOR SYSTEM
==================================================

Primary Background:
- Warm Ivory / Off White
- #FAF8F3
- Use this as the dominant website background.

Secondary Background:
- Soft Champagne / Cream
- #F3EFE6
- Use for alternate sections, cards, navigation areas and subtle visual separation.

Pure White:
- #FFFFFF
- Use for cards, navbar surfaces, forms and elevated components.

Primary Luxury Gold:
- #C9A227
- This is the main brand accent.

Secondary Gold:
- #B88A2A
- Use for subtle borders, icons and secondary accents.

Light Gold:
- #E7D39A
- Use for backgrounds, hover states and subtle highlights.

Primary Text:
- #1C1C1C
- Use for headings and important text.

Secondary Text:
- #5F5A50
- Use for descriptions and supporting information.

Muted Text:
- #8A8478

Dark Accent:
- #151515
- Use SPARINGLY.
- Never make the whole website dark.

Border:
- #DED8CC

==================================================
2. DESIGN PHILOSOPHY
==================================================

The website should feel like a premium hotel brochure transformed into a modern digital experience.

Use:
- Large whitespace
- Strong visual hierarchy
- Elegant typography
- High-quality hotel photography
- Subtle gold details
- Soft shadows
- Thin borders
- Rounded corners where appropriate
- Spacious layouts
- Smooth transitions
- Minimal visual noise

Avoid:
- Excessive gradients
- Neon colors
- Excessive black backgrounds
- Heavy shadows
- Too many rounded cards
- Cheap-looking UI
- Excessive animations
- Overly colorful components
- Generic SaaS dashboard styling

The interface should feel:
"Luxury, but not flashy."

==================================================
3. NAVBAR
==================================================

Use a light navbar similar to the approved reference design.

Navbar:
- White / warm-white background
- Subtle gold bottom border
- Very subtle shadow
- Premium spacing
- Centered Liv.inn logo
- Logo should slightly overlap the navbar and hero section.

Navigation structure:

LEFT:
HOME
ABOUT
ROOMS & FACILITIES

CENTER:
LIV.INN LOGO

RIGHT:
LOCATION
CONTACT & ENQUIRY
WhatsApp
Phone
ENQUIRE NOW

Navigation typography:
- Uppercase
- Letter spacing
- Medium weight
- Dark text
- Gold active state

Active navigation:
- Gold text
- Thin gold underline

Primary CTA:
"ENQUIRE NOW →"
- Gold background
- Dark text
- Rounded pill / slightly rounded rectangle
- Elegant hover animation

Navbar should become mobile-friendly:
- Logo centered
- Hamburger menu
- Enquire CTA can remain visible if space permits
- Mobile menu should use a clean white/cream panel

==================================================
4. TYPOGRAPHY
==================================================

Use an elegant combination of serif + modern sans-serif.

HEADINGS:
Use a premium serif font similar to:
- Playfair Display
- Cormorant Garamond
- Libre Baskerville

BODY/UI:
Use a clean modern font similar to:
- Inter
- Manrope
- Montserrat

Recommended hierarchy:

Hero heading:
Large
Elegant serif
High contrast

Section headings:
Serif
Medium-large
Dark charcoal

Navigation:
Sans-serif
Uppercase
Letter spacing

Buttons:
Sans-serif
Medium/semi-bold
Uppercase or title case

Body:
Sans-serif
Comfortable line height

Do not use too many font families.
Maximum 2 font families.
